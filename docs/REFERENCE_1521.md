# 영상 기반 인테리어 시안

기준: V7.5 BASELINE LOCKED / 81f9035. 구조 및 고정 인테리어 원본 불변.

## 육안 관찰
- 0–4초: 밝은 회벽톤, 밝은 석재 느낌 바닥, 카멜/올리브 브라운 소파, 얇은 금속 프레임 유리 테이블, 긴 커튼.
- 8–16초: 무광 밝은 주방 도어, 상부장 하부 조명, 단정한 얇은 선. 영상 속 주방 배치/아일랜드는 복사하지 않음.
- 20–28초: 흰색 3엽 실링팬, 천장 가까운 커튼, 상부 수납장 아래 간접조명.
- 32–44초: 밝은 타일 욕실, 금속 수전, 평평한 도어와 무광 현관장.

색 비율은 정량 측정 아님: 밝은 중성색을 주조, 소파·커튼을 중간톤, 금속/유리를 작은 포인트로 해석.
영상은 506×380 화면 녹화로 조명색·노출 영향이 있음. 제품명과 정확한 RGB를 영상으로 확정하지 않음.

## 미확정
천장 속 깊이, 에어컨 모델/배관, 조명 배선, 팬 설치 최소 이격, 커튼박스 실측은 확인 불가.
새 설비는 모두 PROVISIONAL_INTERIOR_ONLY. 에어컨은 외부에서 보이는 패널만 시각화하며 천장/슬래브를 절삭하지 않음.
욕실과 현관 구조·문은 원본을 유지. 참고 영상의 내력벽은 가져오지 않음.

## 단계
1. 천장 설비·조명·커튼박스: DESIGN_V1.json / design-layer.js.
2. 기존 배치 데이터는 보존하고 가구의 외관 디테일과 커튼을 별도 레이어로 추가.
3. 같은 카메라의 주간/저녁 비교 및 렌더링 확인. 실측·시공 승인이나 사진급 정확도를 의미하지 않음.
